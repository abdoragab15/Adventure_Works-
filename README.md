# Adventure_Works_Dashboard

#Short_Describtion
This is a data analysis project for Adenture Works store creating an interactive dashboard to help in decision making 

#Tools_Used
- Power BI Desktop --> main data visualization platform used for dashboard creation
- Power query --> data transformation and cleaning
- Power Pivot --> Data Modelling
- Dax --> Calculated Measures , Dynamic Visuals
